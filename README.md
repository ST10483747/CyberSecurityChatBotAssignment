# Cybersecurity Awareness Chatbot

Overview
A WPF desktop application that educates users about cybersecurity.

 Features
- Interactive chat interface
- Voice greeting on startup
- Topics: passwords, phishing, scams

 How It Works
1. User enters name
2. Asks cybersecurity questions
3. Bot provides educational responses

 Technologies Used
- C# / .NET 8.0
- WPF for UI
- System.Media for audio

 Code Structure
- MainWindow.xaml.cs: UI logic and event handling
- Chatbot.cs: Response generation logic
- VoiceGreeting.cs: Audio playback
